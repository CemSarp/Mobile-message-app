## Overview

Mobile-message-app is a full-stack solution designed to enable real-time social communication within mobile applications. It combines secure user authentication, instant messaging, and social features like friend requests and group chats to foster seamless connectivity.

**Why Mobile-message-app?**

This project streamlines the development of social messaging features with a robust architecture that includes:

- 🟣 **🔒 Authentication & Security:** JWT-based login and registration ensure secure user sessions.
- 🟢 **🌐 Real-Time Communication:** WebSocket integration supports instant messaging and live updates.
- 🔵 **🤝 Social Interactions:** Manage friend requests, friendships, and group chats effortlessly.
- 🟠 **🛠 Modular Frontend & Backend:** React Native frontend with RESTful APIs and scalable data models.
- 🟡 **🚀 Developer-Friendly:** Clear architecture, comprehensive services, and repositories for easy customization.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** Java
- **Package Manager:** Maven

### Installation

Build Mobile-message-app from the source and install dependencies:

1. **Clone the repository:**

    ```sh
    ❯ git clone https://github.com/CemSarp/Mobile-message-app
    ```

2. **Navigate to the project directory:**

    ```sh
    ❯ cd Mobile-message-app
    ```

3. **Install the dependencies:**

**Using [maven](https://maven.apache.org/):**

```sh
❯ mvn install
```
**Using [maven](https://maven.apache.org/):**

```sh
❯ mvn install
```

### Usage

Run the project with:

**Using [maven](https://maven.apache.org/):**

```sh
mvn exec:java
```
**Using [maven](https://maven.apache.org/):**

```sh
mvn exec:java
```

### Testing

Mobile-message-app uses the {__test_framework__} test framework. Run the test suite with:

**Using [maven](https://maven.apache.org/):**

```sh
mvn test
```
**Using [maven](https://maven.apache.org/):**

```sh
mvn test
```
